## معماری اطلاعات (V2)

پنج تب اصلی:

1. **داشبورد** — شمارش معکوس آزمون، ادامه مطالعه، برنامه امروز، درصد آمادگی
2. **مطالعه** — نقشه راه، مرورگر مقررات ملی (مبحث ← فصل ← بند) با متن واقعی، دروس
3. **تمرین** — تمرین رسمی / تألیفی / مبحثی / اشتباهات / نشان‌شده‌ها + فیلتر پیشرفته + تمرین سریع
4. **آزمون** — نوبت‌های رسمی با ترتیب و شماره‌سؤال دقیق، آزمون جامع مولّد، آزمون سفارشی، سریع
5. **تنظیمات** — پروفایل، لایسنس، حالت تاریک، نسخه محتوا و شفافیت بازبینی

به‌علاوه: جست‌وجوی سراسری (مقررات + سؤالات)، نشان‌گذاری، یادداشت، گزارش خطا، تاریخچه تلاش‌ها.

## پشته فناوری

- **Next.js 16** + React 19 + TypeScript
- **Tailwind CSS 4** با توکن‌های معنایی طراحی (Light/Dark)
- **Zustand** (persist) برای وضعیت کاربر
- فونت **وزیرمتن** (۴ وزن) — RTL درجه یک
- محتوای آفلاین‌محور از JSON استخراج‌شده از SQLite واقعی

## اجرا

```bash
cp .env.example .env
npm install        # یا bun install
npm run dev        # http://localhost:3000
```


## اصول غیرقابل‌امتناع

- **دقت محتوا مقدم بر هر چیز**: هیچ محتوای رسمی ساختگی نیست؛ سؤالات رسمی و تألیفی کاملاً تفکیک‌شده‌اند و پیشینه (نوبت آزمون، شماره سؤال، مبحث، بند، صفحه) حفظ می‌شود.
- **نسخه‌بندی مقررات**: مقررات هرگز بازنویسی نمی‌شوند؛ نسخه‌های جدید در کنار نسخه‌های قدیمی نگهداری می‌شوند.
- **شفافیت وضعیت**: موارد نامشخص با UNVERIFIED علامت می‌خورند و وارد صف بازبینی می‌شوند.
- **آفلاین‌محوری**: همه امکانات اصلی بدون اینترنت کار می‌کنند.

## وضعیت و مسیر پیش‌رو

این نسخه، مرجع کامل V2 روی محتوای واقعی است. مهاجرت به React Native (Expo SDK 54) طبق فازبندی مستند V2 و طرح SQL موجود در `docs/` ادامه خواهد یافت. موارد وابسته به سورس RN (ساخت AAB، پاک‌سازی manifest، QA دستگاه) در گزارش اجرا با وضعیت BLOCKED و راه‌حل مستند ثبت شده‌اند.
