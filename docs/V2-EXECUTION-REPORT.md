## ۹. تست‌های اجرا شده (شواهد مرورگری، فاز ۲۰-۲۱)

3. تمرین → سؤالات رسمی → سؤال واقعی «مهر ۹۹ · س ۱» → پاسخ → بازخورد + توضیح + پنل منبع (بند/نقل‌قول/صفحه) ✅

6. دارک‌مود کامل + نمای موبایل ۳۹۰×۸۴۴ ✅
7. ESLint: 0 error. هیچ خطای runtime در کنسول مرورگر.
8. تاریخچه آزمون در داشبورد/آزمون نمایش داده می‌شود (scoreAttempt روی attempt ذخیره‌شده — بازتولیدپذیر).
